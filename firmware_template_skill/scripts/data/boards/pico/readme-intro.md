The firmware was generated by the [embedded_bedrock](https://github.com/romixlab/embedded_bedrock) firmware
template and talks to the PC over the board's own USB (the micro-B connector), which also powers it; a Raspberry Pi
Debug Probe on the 3-pin SWD header flashes it and carries its defmt log. `bedrock_fw.json` records the generator
answers; see AGENTS.md.
